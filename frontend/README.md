# Демонстрационный интерфейс

Статическая страница `demo.html`, обслуживаемая FastAPI по `/demo`.
Сборка Node/Next.js для неё не требуется. Запуск и проверки описаны в корневом README.

UI вызывает `/api/cases/plan`, затем `/api/cases/search-with-evidence` с тем же
описанием и готовым планом. Оценки хранятся в localStorage и выгружаются в JSON;
на backend не отправляются. Источник цитаты берётся из `evidence_document`.
Для каждого обязательного признака карточка показывает результат локальной
проверки словоформ в PDF. Совпавшие слова подсвечиваются в точной цитате;
отдельно различаются отсутствие слов и невозможность проверить PDF.
По умолчанию проверяются до шести PDF. Явная галочка включает смысловую оценку
GigaChat с передачей описания, обязательных признаков и не более пяти коротких
фрагментов каждого PDF. В том же вызове модель оценивает каждый признак отдельно;
положительные оценки привязаны к конкретному переданному фрагменту;
короткая цитата подсвечивается только если дословно присутствует в нём;
без неё или при ошибке модели используется локальный предварительный ранг.
Отсутствие признака в отобранных фрагментах не доказывает его отсутствие в PDF.
Пользовательские оценки на порядок выдачи автоматически не влияют.
