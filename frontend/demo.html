Поиск судебной практики по описанию ситуации

GigaChat составляет поисковый план. Сервис получает кандидатов и проверяет PDF. При разрешении смысловой проверки модель сравнивает предмет спора и совокупность обязательных условий с цитатами из акта. Подтверждённые цитатами совпадения показаны отдельно от кандидатов, требующих проверки. Сверяйте выводы с оригиналом.

Поиск страниц и загрузка PDF расходуют операции источника. Извлечение текста и повторная проверка сохранённого PDF выполняются локально. План и смысловая проверка отдельно используют GigaChat.

Обычные режимы проверяют ограниченную часть выдачи. Режим по периодам проходит все формулировки плана за выбранные даты (без ограничения дат: с 1900 года по сегодня), дробит большие выдачи и сохраняет позицию. Каждая кнопка продолжения запускает одну порцию. Полнота зависит от доступности и охвата источника.

Образец ищется отдельно по номеру и помечается в результатах. Он помогает проверить понимание условий, но не подтверждает качество поиска по описанию. Его поиск входит в лимит порции.

Без смысловой проверки результаты остаются предварительными: совпадение слов не подтверждает совокупность условий.

Результаты проверки

Для рекомендации модель должна подтвердить цитатами все обязательные условия в одной ситуации. «Подтверждение не найдено» означает недостаток оснований в прочитанном материале. Техническое качество PDF, рассмотрение вопроса по существу и релевантность дела оцениваются отдельно.
