Поиск судебной практики по описанию ситуации

GigaChat составляет поисковый план. Сервис проверяет слова обязательных признаков в тексте найденных PDF и показывает цитаты с подсветкой. Если вы разрешите передачу фрагментов PDF, модель дополнительно оценит сходство дела и каждый обязательный признак по этим фрагментам. Любую оценку стоит проверить по самому акту.

Оценки сохраняются в этом браузере. Их можно выгрузить файлом и передать команде.
Повторный запуск снова обращается к Parser API. План GigaChat сам по себе его лимит не расходует.

Дела упорядочены по оценке сходства. Для каждого обязательного признака показана отдельная проверка слов в PDF. Совпадение слов не подтверждает факты или юридическую релевантность. Оценка акта — полезность конкретного PDF; оценка дела — соответствие запросу дела, в котором может быть несколько актов.
