# Court Semantic Search

Сервис для семантического поиска судебной практики по описанию фактической ситуации.

## MVP

Пользователь описывает кейс естественным языком. Система:

1. анализирует запрос и выделяет факты и юридические концепции;
2. генерирует несколько поисковых формулировок;
3. получает кандидатов через API RAS;
4. извлекает текст судебных актов;
5. выполняет семантический reranking;
6. группирует документы по номеру дела и обогащает данные через KAD;
7. выбирает наиболее содержательный судебный акт;
8. формирует summary, обстоятельства дела и позиции сторон.

## Архитектура

```text
Frontend (Next.js)
        |
        v
Backend API (FastAPI)
        |
        +--> Query Analyzer / Query Generator
        |
        +--> Court Provider
        |      +--> RAS API
        |      +--> KAD API
        |
        +--> PDF/Text Extraction
        |
        +--> Semantic Reranker
        |
        +--> Case Grouper / Instance Ranker
        |
        +--> LLM Case Analyzer
```

## Структура

```text
backend/   FastAPI и AI/search pipeline
frontend/  Next.js интерфейс
```

Внешние источники судебных данных подключаются через provider-адаптеры, чтобы можно было переключаться между Parser API и API-CLOUD без изменения основной логики приложения.

## Статус

Проект находится на этапе создания MVP. Доступы к RAS/KAD API ожидаются, поэтому сначала используется MockProvider.
